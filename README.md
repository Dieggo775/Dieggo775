## 🚀 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e apaixonado por tecnologia. Gosto de construir aplicações completas, do banco de dados ao último pixel da tela, com código limpo e bem estruturado.

Cada projeto é uma desculpa para aprender algo novo, e cada bug é só um mistério esperando para ser resolvido. 🕵️

- 💻 **Full Stack de coração:** backend e frontend no mesmo pacote

- ☕ **Combustível:** Java, JavaScript e muito café
- 🎯 **Compromisso:** código limpo, escalável e fácil de manter
